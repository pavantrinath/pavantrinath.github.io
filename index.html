Wait, what just happened?

The model fits a polynomial to the visible points using least squares with a small numerical stabilizer. Extra degrees let it bend more, which can fit noise instead of the underlying pattern. The unseen points follow the same hidden curve but were never used for training. Reveal them to see how well the model generalizes. Error is mean squared error in normalized chart coordinates. Complexity is capped by the number of observations.
